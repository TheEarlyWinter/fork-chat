# 已知问题与阶段性重构边界

本轮只抽取连线、布局和快捷键模块，保留现有行为；不是稳定版发布，也不宣称完成视口虚拟化或性能优化。以下问题没有在本轮顺带修复。

## UI-001：弹窗中的 Delete 可能触发画布级联删除（较高风险，遗留问题）

- 位置：`ui/assets/panel-shortcuts.js` 的 `bindKeyboardShortcuts`，以及 `panel.js` 的 `closeCardHierarchy`。
- 条件：画布已有选中卡片，弹窗打开，焦点落在按钮等非输入控件上，再按 Delete。
- 结果：全局快捷键没有隔离弹窗，仍可能调用底层画布的级联删除。影响的是 App 自有卡片及其后代，不是 Hana 本体会话删除。
- 验证：离线回调复现，重构前后处理器均存在该路径；不是本次抽取引入的新回归。
- 暂避：弹窗中不要使用 Delete；重要画布先保留副本。
- 待修：统一模态/焦点作用域保护，覆盖按钮、select、输入法组合态与快捷键处理边界，并补集成回归。

## LAYOUT-001：不等长多父路径可能排到错误层级（遗留问题）

- 位置：`ui/assets/panel-layout.js` 的 `computeAutoTidyPositions`。
- 原因：已计算最长路径 depthMap，但真正分配横坐标仍使用首次递归到达节点时的 depth，节点排过后不再更新。
- 最小结构：`R → Short → Merge` 与 `R → Long → X → Merge`。先走短路径时，Merge 可能与父节点 X 落在同一列。
- 验证：离线最小反例已复现；原内联实现产生相同结果。
- 暂避：复杂多父画布先手动排版，自动整理后检查合流节点位置。该问题影响布局，不会直接修改父子关系。
- 待修：按统一的最长路径拓扑层级布列，并对共享子节点的纵向占位制定策略；新增非对称多父 DAG 回归，不能只验证普通树。

## LIFECYCLE-001：快捷键解绑接口尚未接入入口生命周期

- 新模块提供 cleanup，但 `panel.js` 目前直接调用绑定函数，未保存返回值，也未在统一 dispose 中调用。
- 这是解耦的未完成项；本轮没有证据证明普通页面关闭时已发生线上监听泄漏，但重复挂载/主动销毁的生命周期尚未闭环。
- 待修：保留 cleanup 并接入统一销毁流程，测试重复绑定、解绑和重新挂载。

## PERF-001：虚拟化、增量重绘尚未实现

- 连线层仍清空 SVG 后全量重建；每条边中还会查找父卡和扫描兄弟节点。
- 拖拽/缩放卡片时仍直接请求连线重绘；卡片 DOM 没有按视口裁剪。
- 拆文件提升可维护性和可测试性，不等于已减少 Layout 开销。尚无节点规模/帧率基准，不承诺百级节点流畅度。

## 验证范围与测试入口

- 本地完整离线套件复跑：314 pass / 0 fail，包括回传防重、落盘失败闭锁等既有测试。
- 独立对照：100 组确定性 DAG 新旧布局输出一致；新布局计算不修改输入卡片。
